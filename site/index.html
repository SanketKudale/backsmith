USE YOUR DATABASE

One CLI, seven database targets.

Backsmith generates native dependencies and configuration for each engine. Relational projects use JPA and Flyway; MongoDB projects use Spring Data MongoDB. Integration tests run against the selected engine, and H2 is used only when you choose it.

PostgreSQL

UUID, JSONB, timestamp-with-time-zone, Flyway, and PostgreSQL Testcontainers.

MySQL

MySQL Connector/J, native JSON and binary UUID storage, Flyway, and MySQL Testcontainers.

MariaDB

MariaDB JDBC, native JSON-compatible storage, Flyway, and MariaDB Testcontainers.

SQL Server

Microsoft JDBC, uniqueidentifier, datetimeoffset, Flyway, and licensed SQL Server containers.

Oracle

Oracle JDBC, RAW UUIDs, timestamp-with-time-zone, Flyway, and Oracle Free containers.

H2 and MongoDB

Explicit H2 projects for local use, or document-native MongoDB projects with repositories and container tests.

FREE TO USE

Install Backsmith.

Java 21 or newer is the only runtime prerequisite. Every archive is published with SHA-256 checksums.

macOS / Linux

curl -fsSL https://github.com/SanketKudale/backsmith/releases/latest/download/install.sh | sh

Windows PowerShell

irm https://github.com/SanketKudale/backsmith/releases/latest/download/install.ps1 | iex

Homebrew

brew install SanketKudale/tap/backsmith

Scoop

scoop bucket add sanketkudale https://github.com/SanketKudale/scoop-bucket
scoop install sanketkudale/backsmith

JBang

jbang app install backsmith@SanketKudale

Manual download

Download the executable JAR, ZIP, or TAR.GZ release.
