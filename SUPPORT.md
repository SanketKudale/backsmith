# Support

Backsmith is a community-maintained pre-1.0 project.

- Ask usage and architecture questions in [GitHub Discussions](https://github.com/SanketKudale/backsmith/discussions).
- Report reproducible bugs through the issue templates.
- Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/SanketKudale/backsmith/security/advisories/new).

Do not post secrets, credentials, private source code, or sensitive generated configuration.
